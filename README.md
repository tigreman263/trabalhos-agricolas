# Trabalhos Agrícolas

App de página única (um ficheiro HTML) para gerir trabalhos agrícolas:
clientes, trabalhos por hora, máquinas e horas, manutenções, caixa (ganhos e despesas),
conta corrente, recibos e relatórios com gráfico personalizado.

## Ficheiros

- `trabalhos-agricolas.html`: a aplicação completa (HTML, CSS e JavaScript num só ficheiro).

## Notas

- Os dados vivem na base de dados da plataforma onde a página é publicada; este repositório
  guarda apenas o código.
- Ainda não há testes automáticos.
